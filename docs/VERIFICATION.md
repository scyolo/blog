## 已发现并处理的问题

1. 原始构建依赖 Google 字体，当前网络实际失败。改为本地/系统字体。
2. 上游锁文件含多项安全告警，升级实际依赖并重新审计，不能只修改版本字符串。
3. Windows 不支持原构建脚本中的 cp。改为无 shell 的跨平台 Node 构建与固定路径清理。
4. 上游发布逻辑把漏填 draft 当公开，存在提前窗口且开发不能预览草稿。对应回归先失败后通过。
5. 地址取决于文件目录、旧文修改影响排序。已修复辅助函数；显式 slug schema/loader 和真实产物验收仍待完成。
6. 上游格式检查忽略根目录新增文件。使用 Prettier 自身的忽略解析 API 建立回归，避免命令成功却没有覆盖目标。
7. 审计门禁需要拒绝汇总/明细矛盾、级别变化、已有补丁及过期例外。已建立用例验证。

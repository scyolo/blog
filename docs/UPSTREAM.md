## 已验证的适配

原始锁文件能够安装，但生产构建依赖远程字体；当前网络下真实失败。安全审计同时发现 Astro 等依赖的待修复告警。因此以该主题为源码基础，而不是将旧锁文件视为可发布成品。

- 移除未使用的 MDX 编译链、动态 OG、Google 字体网络构建依赖及相应入口。
- 使用静态分享图；用文件存在检查代替将 public/* 导入为 JavaScript。
- 跨平台 Node 构建器只清理固定、经边界检查的产物路径，不使用 shell 删除或 cp。
- 保留 Astro 内容集合、布局、RSS、分页、标签与主题基础，在后续阶段逐项用测试约束修改。
- 不导入上游 Docker、部署工作流、编辑器配置或宣传文档。

## 升级纪律

记录每次升级原因和构建、类型、测试、依赖审计结果。不得直接合并上游全量变化；必要安全修复按项目实际依赖评估。阶段日志中的“未验证”不等于通过。

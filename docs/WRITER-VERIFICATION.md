## 真实 GitHub API 验证

另行使用已有的 GitHub CLI 授权，在从部署分支创建的临时分支上执行真实请求：

1. 核验博客所有者身份，读取现有三篇文章。
2. 创建 UTF-8 Markdown 草稿的 blob、目录树和提交，以 `force:false` 更新临时分支。
3. 重新读取文章，核对正文、草稿标记和文件 SHA。
4. 提交过期文件 SHA，确认被拒绝且不覆盖远端版本。
5. 核对分支未被外部更改，然后删除临时分支。

正式分支未加入验收文章。浏览器发布交互使用 GitHub 响应模拟，真实写入通过上述独立 API 检查完成；两者不冒充一次使用作者细粒度令牌的线上端到端发布。

## 使用边界

- 首次在线发布需要作者创建仅授权 `scyolo/blog` 的细粒度令牌：Contents 读写、Actions 只读。令牌只在当前页面内存中使用，刷新后重新连接。
- 图片应先放入仓库的 `src/assets`；本轮没有图片上传界面。
- 未来文章需要到期后重新构建，未设置自动定时发布。
- 公开仓库里的草稿源码仍可公开读取；本机草稿不自动同步到仓库。
- 下架会更新网站，不删除 Git 历史或外部读者缓存。
